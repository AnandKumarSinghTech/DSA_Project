🚀 DSA Solver & Visualizer
Welcome! This is a simple, lightweight web application designed to help visualize and solve Data Structures and Algorithms (DSA) problems.

Most web apps use JavaScript for everything, but I wanted to leverage the speed of C++ for the actual logic while keeping the interface modern with React.

🛠️ The Tech Stack
Frontend: Basic React.js (for a clean, interactive UI).
Backend Glue: Node.js / Express (to bridge the frontend and the C++ logic).
The Brain: C++ (all core DSA algorithms are written here for maximum performance).
Database: None! (Currently stateless and lightweight—no login or signup required).
✨ Features
High Performance: Algorithm logic is powered by compiled C++.
Simple UI: No cluttered menus. Just pick an algorithm and see it in action.
No Friction: No need to create an account or manage a database. Just clone and run.
🚀 Getting Started

📂 Project Structure
/frontend: Contains the React components and styles.
/backend: The Node.js server that handles API requests.
/backend/cpp_logic: This is where the magic happens—C++ scripts for various algorithms.
